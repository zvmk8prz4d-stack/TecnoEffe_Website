# Tecnoeffe — versione GitHub Pages

Questa cartella contiene il sito statico pronto per GitHub Pages.

1. Carica **il contenuto di questa cartella** nella radice del repository `TecnoEffe_Website`.
2. Su GitHub apri **Settings → Pages**.
3. In **Build and deployment**, scegli **Deploy from a branch**.
4. Seleziona **main** e **/(root)**, poi premi **Save**.
5. Il sito sarà disponibile su: https://zvmk8prz4d-stack.github.io/TecnoEffe_Website/

Il file principale è `index.html`. Non caricare soltanto lo ZIP.
